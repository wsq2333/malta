# Runner Jobs

Jobs are generated by `internal/executor/kubernetes/job.go` from an immutable Run.
Do not manually apply a second copy: the API owns request/attempt IDs and the
results handshake. Use `malta run start --executor kubernetes`.

One completion, one parallel Pod, `backoffLimit: 0`, `restartPolicy: Never`,
`podReplacementPolicy: Failed`, an active deadline, no TTL before persistence.
The worker atomically creates `/results/<attempt>/claimed` and never removes it.
A replacement Pod therefore cannot start the same load again. This depends on
atomic mkdir on the results filesystem; validate this property for each CSI.
A claim is not a general distributed lock or a guarantee of exactly-once completion.

Volumes: existing benchmark PVC at `/bench`, immutable ConfigMap at `/etc/malta`,
independent RWX results PVC at `/results`, 64 MiB temporary volume at `/tmp`.
Runner has no API credentials, capabilities, hostPath, privileged mode or FUSE mount.
