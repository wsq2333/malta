# Management-only deployment

Use this profile to deploy the UI/API, case library, environment/version registry,
and imported result comparison before configuring Runner Jobs. It does not execute,
recover, reconcile or cancel managed runs. No Kubernetes API token/RBAC or test/results
PVC is needed. Keep SQLite on its own RWO disk PVC; one replica and Recreate updates.

Render with a digest-pinned Server image (including `--management-only` support):

```sh
python3 scripts/render-management.py --namespace malta-dev \
  --server-image REGISTRY/infra/malta@sha256:IMAGE_DIGEST \
  --storage-class alicloud-disk-essd --state-size 20Gi \
  --image-pull-secret acr-credential-secret-aggregation \
  --alibaba-internal-lb --allow-unauthenticated \
  > config/deploy/sample-dev.json
```

The renderer never contacts Kubernetes. The output creates a dedicated Namespace,
ServiceAccount, persistent state PVC, single Server Deployment and Service. The Alibaba
annotation explicitly requests an intranet LoadBalancer; verify its assigned private IP.
The pull Secret must exist in the target namespace or be provided by its credential
controller; creating a namespace does not inherit another namespace's Secrets.
Do not store kubeconfig, registry credentials or rendered environment configuration in Git.

`--allow-unauthenticated` explicitly enables API access without a token. Anyone able to
reach the private endpoint can manage its data. Alternatively render with `--token-secret
malta-api-token` and provision that Secret separately; the default server still requires
a token for non-loopback binding. No token is generated by this renderer.

Apply with explicit kubeconfig/context only after deployment authorization. Check PVC
Bound, Deployment Available, imageID, LoadBalancer ingress and `/api/v1/health`, then
check `/api/v1/capabilities` reports `management_only: true` and `managed_runs: false`.
To enable execution later, publish a separate fio Runner image and use the full
Kubernetes profile with benchmark/results PVCs, executor configuration and RBAC.
Deletion of the Deployment/Service stops the service and releases the LoadBalancer;
retain the namespace and PVC unless data deletion is explicitly intended.
