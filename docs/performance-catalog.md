# 性能测试概览与历史

测试中心 → 性能测试采用硬件范围选择、测试项目分组和分页历史。现有运行、用例、基线及证据不变；无数据库迁移。

## 浏览范围

硬件范围沿用云类型、角色数量和机型的展示分类。实际环境按已登记的 `config.cluster` 与区域区分；未登记集群身份时，按执行快照隔离，不将相同机型视为同一物理集群。硬件分类可能含不完整历史快照，详情中仍保留真实缺失信息。

支持版本、负载类型、读写类型、文件/块大小、状态、文本、日期及单个执行快照筛选。大小筛选填写字节数，界面显示换算后的 KiB/MiB。范围改变返回第一页；详情返回与浏览器前进后退保留查询状态。日期按浏览器所在时区的起止日转换为 RFC3339。

## 分组及指标

测试项目由文件系统、负载类型与用例 ID 标识；没有用例引用的历史记录使用负载名称作为项目身份。不同名称的旧记录不会自动归并到用例项目。

条件组包含完整负载定义（去掉名称）、完整环境（去掉 ID/名称）、目标路径、工具版本和 Malta 版本。用例修订与被测软件版本不直接参与条件键，实际参数变化会拆分条件组。环境中任何配置变化，包括采集时间等记录字段，也可能产生新条件；首版选择保守拆分，后续可引入经过审计的字段分类，避免误合并。

项目有多套条件时不展示混合指标，必须进入条件列表。最新运行状态与最新完整成功结果独立展示；只有 succeeded 且 result_state=complete 的记录参与成功结果选取。显示的是一次运行内的独立重复中位数，跨运行不再取最大值或平均值。多个并发点或混合指标显示指标数量并进入详情，不混合为单一峰值。

“已设基线”筛选以运行去重计数；同一运行的多个基线名称不重复统计运行次数。原基线对象与名称不变，正式基线仍可在对比页选择。当前概览不自动指定参照基线或计算回归百分比。

历史每页 20 条；选择最多两条完整成功记录进行比较，翻页保留选择，改筛选清空选择。第一条作为参照。比较继续通过原服务端可比性检查，分组不是可比性证明。

## API

`GET /api/v1/run-catalog`，沿用 Bearer 认证及 schema_version=1.0 envelope。

| 参数 | 说明 |
| --- | --- |
| mode | overview（默认）、conditions、history |
| project / condition | 服务返回的分组键；conditions 必须指定 project，condition 同样要求 project |
| environment | 可重复传入环境快照 ID，最多 1000 个；未指定表示全部 |
| version / kind / status | 软件 ID、负载类型、运行状态 |
| operation / file_size / block_size | 数据 I/O 读写类型、文件大小字节、块大小字节；大小为 0 或省略表示不限 |
| from / to | RFC3339，包括边界 |
| search | 最多 200 字节，匹配 Run ID、负载名称、软件标签、环境名称 |
| saved | true 仅匹配已设基线的运行，默认 false |
| limit / offset | 每页 1–100，默认 20；offset 非负 |

返回 `total`（当前模式的项目/条件/运行数）、`run_count`、`succeeded`（完整成功）、`active`、`saved`（去重基线运行数）、`limit`、`offset`，以及 `groups` 或 `runs`。groups 含最新运行和独立的最近成功记录，多条件项目的 latest_success 为 null。runs 是含指标摘要的只读投影；完整证据仍从已有运行详情读取。

分组与统计在服务端读取完整匹配历史，不受旧 `/runs` 500 条页面上限影响。一次请求使用同一 SQLite 读事务。当前使用流式扫描并保留分组代表记录；内存随分组数量增长，查询时间随匹配历史增长。大量持续运行时可进一步增加投影表与索引，不应通过截断历史伪造完整统计。offset 分页在独立请求间不是冻结快照，新任务进入时可能使页边界移动。

旧对比趋势接口仍有最近 500 条成功记录窗口；指定两条记录的直接比较会补载所选记录，不受该列表窗口限制。

## 验证

存储测试覆盖超过 500 条运行、尾页、软件升级归组、权限/重复数/工具条件隔离、最近失败与此前成功分离、范围与状态/日期/读写类型/文件及块大小过滤、基线去重、参数校验和请求取消。API 测试覆盖认证及错误参数。

开发机验证包括 Go 全量测试、store/api 竞态检测、12 项前端测试、TypeScript 检查及生产构建。隔离预览使用 49 条纯合成记录，验收了硬件/集群筛选、条件拆分、失败状态与历史成功结果并列、空状态、三页运行历史、跨页对比、详情返回保留选择、基线筛选重置页码与浏览器后退恢复。未以这些合成指标作为真实性能证据。
