# 工作空间信息组织

侧栏保留性能基线、问题管理、用例管理、软件版本、硬件环境、对比与趋势、使用指南。独立的测试运行入口合并到性能基线。

## 卡片与详情

- 硬件卡片：云类型、各角色机器数量和型号。详情分为硬件配置、测试配置、关联测试；原始快照不变。
- 软件卡片：文件系统、版本名称。详情查询该版本最近500次测试，并展示构建技术信息。
- 用例卡片：名称、负载类型、修订、简述、更新时间。详情以字段展示负载，保留历史修订选择、编辑为新版本、导出和发起测试。
- 问题卡片：标题、类型、解决状态、软件与发现时间。详情保留描述、关联、历史、解决方式与编辑。
- 测试卡片：负载、软件版本、日期、状态、云环境和主要指标。详情保留逐轮指标、取消、设为基线、证据下载及日志。
- 对比页：先展示两个测试摘要、可比性和前三项指标变化，完整指标折叠展示；原比较判定不变。
- 指南：保留任务流程和导航，JSON示例默认折叠，仍可复制和下载。

## 性能基线统一入口

默认页签“已设基线”展示正式命名的基线；同一运行可以对应多个基线名称。另一个页签“全部测试”展示排队、运行中及已结束实验。发起新测试后进入详情，返回全部测试。

列表筛选在打开、关闭详情时保留。实体详情使用 `?page=...&detail=<ID>`，测试详情使用 `?page=baselines&view=all&detail=<RunID>`；浏览器前进/后退同步页面状态。旧 `?page=runs` 自动转换为 `?page=baselines&view=all`，保留原有筛选。

运行列表遵循API最多500条的加载范围。已知但被负载过滤排除的基线不混入结果；未加载的基线在无额外筛选时保留名称和详情入口，详情通过单独请求读取。详情中的版本和硬件关联测试分别按实际ID查询，不借用其他页的过滤结果。

本次仅调整前端和说明，不修改数据库结构、环境/用例引用、plan hash、运行后端、身份权限或比较规则。
