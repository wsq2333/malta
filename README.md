# Malta

Malta 是一个面向分布式文件系统的性能基线测试与可视化分析项目，旨在通过可重复的 Benchmark 和直观的 Web UI，对比不同日期、版本及配置下的性能极限，追踪性能变化，并计划接入 Agent 辅助分析与瓶颈诊断。

项目名称取自地中海岛国马耳他。

## 项目目标

- **性能基线**：建立可重复执行的 benchmark，统一记录测试负载、集群配置、软硬件环境及测试结果。
- **可视化展示**：通过 Web UI 清晰展示吞吐量、IOPS、延迟及资源使用情况。
- **跨日期与版本对比**：对比不同日期、文件系统版本和配置下的性能上限，识别性能回退与提升；保留环境与负载信息以判断结果的可比性。
- **Agent 分析（后续规划）**：提供结构化结果与分析接口，支持性能瓶颈诊断、异常解释和优化建议。

## 初始状态

当前仅建立项目目录并明确定位，尚未选择技术栈或实现测试与 UI 功能。
